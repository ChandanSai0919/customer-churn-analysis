# Customer Churn Analysis

Data analysis project to identify factors driving customer churn and build a model that predicts which customers are likely to leave.

## Tech Stack
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

## Contents
- Exploratory data analysis (EDA) of customer data
- Feature engineering and preprocessing
- Churn prediction model with evaluation metrics
- Visualizations of key churn drivers

## How to Run
1. `pip install pandas numpy scikit-learn matplotlib seaborn jupyter`
2. Open the notebook in Jupyter and run all cells

## Dataset
Customer churn dataset (included in this repository).
